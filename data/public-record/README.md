## Complaint counts (`cfpb-complaints.json`)

**How it was obtained.** One request per company string to the CFPB complaint search API (`https://www.consumerfinance.gov/data-research/consumer-complaints/search/api/v1/?company=…&size=10000&no_aggs=true`). The full responses are kept in `raw/local/` (not committed: they hold complaint IDs, ZIP codes and tags) and only counts are committed. In the pre-coding check (October 22, 2026) the API's date_received was compared with the database's CSV export for all 2,654 records of these five company names, and every date matched; the build does not repeat that comparison.

| GreenSky | GreenSky, LLC | 698 | 2013-08-13 | 2023-01-21 | sub_product 15, sub_issue 621, state 9 |
| GreenSky | GREENSKY OPERATIONS, LLC | 576 | 2023-01-27 | 2026-10-05 | (combined above) |
| Dividend Finance | Dividend Finance Inc. | 39 | 2021-06-19 | 2023-03-22 | sub_issue 28 |

**Cleaning.** Fields read: date_received, product, sub_product, issue, sub_issue, state, company_response, timely, company. Never read or stored: complaint_what_happened, zip_code, tags, complaint_id, company_public_response, submitted_via, date_sent_to_company. Counts only. Each company string is downloaded whole; the response must contain every record it reports. Records are counted by the first seven characters of date_received (the date the CFPB received the complaint, as in the database's CSV export). Months with no complaints count as zero. A missing category value is counted as "(not given)". Category names are the database's own; the product names changed during the window and are not merged. monthlyByIssue lists only non-zero cells. No narrative, ZIP code, tag, complaint ID or other free text is stored.

## Peer lenders (`peers-quarterly.json`)

**How it was obtained.** SEC XBRL company facts (`https://data.sec.gov/api/xbrl/companyfacts/CIK##########.json`), one file per filer, committed in `raw/`.

| Oportun | OPORTUN FINANCIAL CORPORATION | 1538716 | 379 | 10,200 | 1,571,038 |
| OneMain Holdings | ONEMAIN HOLDINGS, INC. | 1584207 | 624 | 24,014 | 3,630,455 |
| GreenSky | GREENSKY, INC. | 1712923 | 274 | 5,626 | 897,339 |

**Cleaning.** Same concept lists and two-stage deduplication as the case-study snapshot; one concept per metric per filer, so a series never mixes definitions. Only facts from periodic reports (10-K, 10-Q and their amendments) are used; facts from other forms, such as the rounded figures in proxy statements, are excluded. The latest-filed value is kept, so restatements are used, except that a later-filed zero contradicting an earlier non-zero value for the same period is a disagreement between filings: that period is a listed gap, with both values recorded. A discrete quarter not filed as such is year-to-date minus the previous year-to-date within the filer's fiscal year (marked derived, citing both facts). Calendar quarters are matched on period end dates. Quarters after a filer's latest filed quarter are outside its window; every gap inside it is listed and none is filled.

**After EDA.** Window 2019Q1 to 2026Q2; case-study window 2021Q1 to 2023Q2. Cells are reported / derived / missing quarters inside each filer's window.
